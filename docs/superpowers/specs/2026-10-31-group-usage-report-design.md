# 分组用户用量图表报表方案

参考页面：https://www.huanfangyouxu.top/admin/dashboard

在现有“用户消息 → 用户用量”页升级导出功能。沿用当前分组与近1、7、14、30天筛选，导出覆盖该分组全部匹配用户，不受页面分页限制。页面提供“导出 Excel”和“导出 HTML”两个明确入口。用户已确认：根据权限，只导出选中的一个分组；未选择具体分组时不可导出。

## 推荐结构

Excel 使用真正的 `.xlsx` 工作簿，图表可在 Excel 中编辑。首页为分组概览，随后是个人分析、用户明细、每日明细和模型明细。个人分析用一个用户选择器切换，不为每个人复制一张工作表。概览展示请求数、总 Token、活跃人数、实际消费，并配置用户用量柱状图、每日趋势折线图、模型占比图；明细可筛选、冻结表头并按列设置数字格式。

HTML 是无需登录、无需联网即可打开的单文件报表。视觉沿用现有管理仪表盘的浅色卡片、品牌色、简洁图表与留白。顶部清楚展示分组、统计区间和导出时间。默认显示全组，用户选择器或点击用户排行可切换到某个人，概览、趋势、模型分布和明细同步变化。图表支持悬停看数值，表格支持搜索与排序，布局适配电脑和手机。

HTML 布局：

```text
幻方有序 · 分组用量报告       分组 / 时间范围 / 导出时间
查看范围：[全部用户 / 某位用户]
请求数      总 Token      活跃用户      实际消费
每日 Token 与请求趋势                 模型使用占比
用户用量柱状排行                       模型明细
用户明细：搜索 / 排序 / 点击切换个人
```

导出的是选定区间的数据快照，页面明确标明统计截止时间。重新导出获取新数据，不把离线文件标成实时监控。

## 统计口径与成员范围

- 指定分组时，每个人的数字只包含该分组内的用量，不混入他在其他分组的使用。
- 成员包含该分组有用量的用户，以及通过密钥、明确分组授权或订阅绑定到该分组的现有用户；绑定但区间内没有调用的人也显示为0。
- 管理员可选择任意具体分组；普通查看者只能导出获授权的具体分组。两种新格式和既有CSV都拒绝缺少分组、无效分组或未授权分组，不提供全部分组导出。
- 请求数与输入、输出、缓存读取、缓存创建 Token 分别统计，总 Token 不漏算缓存创建。
- 实际消费与标准费用分开标明，金额延续美元账本口径。报表不包含 API Key、消息正文、供应商凭据或供应商内部成本。
- 汇总、个人、每日和模型数据使用相同起止时间与同一数据库快照，保证各图和明细能够对账。

## 实现边界

新增报表数据聚合与两种格式生成，复用既有管理员和分组查看者鉴权。保留指定分组的原 CSV 导出兼容性。无需迁移数据库，不修改模型价格、分组倍率、密钥路由、消息留存或计费流程。

HTML 的数据、样式、脚本和图形全部内嵌，打开文件不访问第三方资源。用户名与模型名按文本处理，防止 HTML 脚本注入；Excel 文本字段不作为公式执行。

## 结构选择

推荐上述五张工作表：分组总览与个人分析服务两个阅读层级，另外三张明细支撑筛选与对账。另一种可行结构是两张工作表，将所有图形和个人分析集中在首页、全部明细集中在第二页；文件标签更少，但数据区域较长，按人查看不如推荐结构清楚。

## 验收与上线

使用超过一页的用户、零用量成员、重复用户名、跨分组数据和边界时间测试完整性。核对全组总数等于用户、每日及模型明细合计，个人切换前后图表与数值同步。验证未授权导出被拒绝，修改筛选期间导出仍使用点击时的条件。

检查 Excel 的原生图表、公式、表头、数字格式及实际打开效果；检查 HTML 离线打开、用户选择、表格搜索排序、手机布局、空数据和长名称。相关测试和生产构建通过后部署到现有网站，保留旧版本用于回退，并实际下载两种文件验收。
